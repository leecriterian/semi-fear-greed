# 반도체 공포탐욕지수

미국(SOXX와 구성종목)과 한국(삼성전자·SK하이닉스) 반도체 시장의 공포·탐욕을 0~100으로 나타낸 지수입니다.

- 공개 페이지: 저장소 Settings → Pages에 표시된 주소
- 갱신: GitHub Actions가 한국시간 월~토 저녁 8시 48분에 자동 실행합니다.
- 수동 갱신: Actions 탭 → "공포탐욕지수 갱신" → Run workflow
- 화면: 시장별 지수, 1주·1개월·6개월·1년·2년 전 비교, 최근 2년 그래프(미국은 SOXL 가격, 한국은 바스켓 가격을 겹쳐 표시)

## 계산 방법

- 지표마다 오늘 값이 최근 252거래일 중 몇 % 위치인지 구해 0~100점으로 씁니다.
- 변동성은 높을수록 공포이므로 100에서 뺍니다.
- 지표 점수의 평균이 지수입니다.

| 구분 | 미국판 (6개) | 한국판 (4개) |
|---|---|---|
| 모멘텀 | SOXX의 125일 이동평균 대비 위치 | 바스켓의 125일 이동평균 대비 위치 |
| 가격 강도 | 구성종목 52주 신고가 − 신저가 비율, 10일 평균 | – |
| 참여 폭 | 50일 이동평균 위 구성종목 비율 | – |
| 베팅 방향 | SOXL ÷ (SOXL + SOXS) 거래대금, 10일 평균 | – |
| 변동성 | SOXX 20일 변동성(연율) | 바스켓 20일 변동성(연율) |
| 상대 강도 | SOXX − SPY 20일 수익률 | 바스켓 − 코스피 20일 수익률 |
| 외국인 수급 | – | 두 종목 외국인 순매수 ÷ 거래대금, 20일 합계 |

구간: 0~24 극단적 공포, 25~44 공포, 45~55 중립, 56~75 탐욕, 76~100 극단적 탐욕

## 데이터

- 가격·거래량: Yahoo Finance
- 미국 구성종목: iShares SOXX 보유종목
- 외국인 순매수: Daum 금융(실패하면 네이버 금융)

투자 권유가 아닙니다.

## 파일

- `scripts/build.py`: 데이터를 받아 계산하고 `site/`에 페이지를 만듭니다.
- `template.html`: 페이지 틀입니다.
- `site/data.json`: 날마다 계산한 결과가 기록됩니다.
